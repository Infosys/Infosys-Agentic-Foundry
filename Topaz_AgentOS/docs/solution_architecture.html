Enterprise Context (curated)

Authored domain knowledge that grounds reasoning every turn and makes answers explainable & policy-aware — Enterprise_Context.md, contexts, entities, taxonomy, DOA/judgment matrices, knowledge base, business DBs. Swap it → same engine, new domain.

State & Data (runtime)

Operational stores the platform generates at runtime — sessions, approvals, queue, execution traces, operational twin, evidence bundles.

Two data planes are deliberately separated: Enterprise Context (domain knowledge, read to ground reasoning) vs State & Data (runtime operational stores). The platform/engine is domain-agnostic; Enterprise Context makes it yours.
