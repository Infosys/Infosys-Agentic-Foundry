# Generated Review Artifacts

This folder is reserved for generated or exported HTML review artifacts. These
files can be useful during architecture discussions, but they are not part of
the core AgentPro runtime or package source.

Generated HTML files in this folder are ignored by git via `.gitignore`. Keep
durable source documentation in `docs/*.md` or the relevant package docs.

See [docs/README.md](../README.md) for the master documentation index.
