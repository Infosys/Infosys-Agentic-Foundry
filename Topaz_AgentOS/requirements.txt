# Install:
#   pip install -r requirements.txt

# Artifactory pypi-virtual serves malformed Windows wheels for pure-Python
# packages that ship console scripts (the .exe lands outside site-packages and
# pip rejects the wheel), and also has stale hash fragments for some wheels.
# Both problems go away when pip builds from sdist instead.
# The --no-binary lines below handle this automatically for all known offenders.
# CLEANER ALTERNATIVE: point the index at the pure PyPI proxy (pypi-remote)
# instead of pypi-virtual, which avoids the corrupted local artifacts entirely.
