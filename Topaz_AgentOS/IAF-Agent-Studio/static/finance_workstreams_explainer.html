Topaz AgentOS — Finance Demo Guide

What each workstream is, how it runs, and exactly how to demo it — written for a finance newcomer.

The big idea (in one minute)

A workstream is a finance process — paying supplier invoices, chasing money customers owe us, closing the monthly books, reconciling the bank. Traditionally a person does every step by hand.

Here, an AI agent runs each case (one invoice, one customer, one account) through a fixed sequence of stages, automatically. Most cases flow straight through with no human touch.

But finance needs control. So at key points the agent stops and asks a person to decide — a human gate (HITL, "human-in-the-loop"): before releasing a large payment, writing off a debt, or signing off the close. The human owns the risky calls; the agent does the rest.

We built five workstreams: four straight-line workflows (P2P, O2C, R2R, Treasury) plus a document-reading step — and one advanced graph that reconciles many accounts at once and checks its own work.

stage agent does it automatically ⛔ human gate agent pauses for a person → order of the flow

How the towers connect — the exception cascade

These aren't four islands. When a case hits an exception it creates downstream work in another tower — a missing goods receipt in P2P becomes a GR/IR imbalance at the R2R close; an over-limit customer in O2C hits Treasury's cash; unreconciled Treasury suspense lands back at R2R.

  P2P ─┐
  O2C ─┼──▶  R2R (the sink)  ──▶  External (audit / IR)
  TREASURY ─┘

In the demo data: 68 cascade links, and R2R absorbs ~41% — the classic "everything ends up at the close" story.

Record-to-Report (R2R) · GRAPH mode

Entity Close — parallel & self-checking

The "trustworthy agent" showcase. For one entity, it reconciles all 8 accounts at once (parallel), an independent verifier checks they all balance, any that fail get retried with feedback, and an unresolved break is escalated to a human. This is what a straight-line workflow can't do.

 entity → [8 accounts reconciled in parallel] → JOIN
      → VERIFIER: all balance & within materiality? PASS / FAIL
      → retry the failing ones ×2 → still stuck? ⛔ escalate to Controller
      → journal → post & close

1 · Reset to a clean start (before each demo)

One command puts every workstream back to the identical starting state (same cases, same gate spread) in ~10 seconds. Deterministic — the demo is the same every time.

python3 "$DATA_ROOT/tenants/company/shared/scripts/demo_reset_all.py"

Then hard-refresh the pages. (A cache evict is only needed if you changed skills/config, not for a data reset.)

2 · Open the pages

↗ Workstreams ↗ Finance Console ↗ Observers ↗ HITL Approvals

3 · Run a workstream & show the human gate

  1. On Workstreams, open a workstream and click Run Now (tip: it runs the top-priority pending case — you don't need to run the whole backlog).
  2. Watch the agent chain the stages and pause at a gate (status → awaiting_human).
  3. Flip to Finance Console to see the same numbers in the leadership view, or HITL Approvals to Approve / Reject.
  4. Approve → the workstream continues to the next gate or posts. Reject → it stops. Then reset and go again.

Finance terms — quick glossary

PO (Purchase Order) — what we agreed to buy and for how much.
Goods Receipt (GR) — proof the goods/services were received.
Three-way match — invoice = PO = goods receipt before paying.
GR/IR — "Goods-Received / Invoice-Received" — flags mismatches between the two.
AP / AR — money we owe suppliers / money customers owe us.
Exposure — how much a customer currently owes us.
Credit limit / hold — the max we let a customer owe; a hold pauses activity when breached.
Dunning — the sequence of reminders used to chase overdue payment.
Write-off — accepting a debt won't be paid and removing it from the books.
Period-end close — finalising the monthly accounts so results can be reported.
Flux / variance — the change in a balance vs last month; large ones must be explained.
Materiality — the "big enough to matter" threshold; below it, don't chase.
Journal entry (JE) — a manual accounting adjustment posted to the ledger.
Reconciliation — proving two records agree (bank vs ledger).
Suspense — a holding account for items that can't yet be explained.
Settlement — an outgoing payment (incl. FX) the treasury makes.
Accruals — money owed for things used but not yet billed (e.g. this month's electricity).
Inventory — the value of stock the company holds to sell or use.
Intercompany — money owed between two parts of the same group (error-prone).
Human gate / HITL — a control point where the agent pauses for a person to decide.
Verifier — an independent check that says PASS/FAIL and forces a retry if the work is wrong.
Straight-through — a case that flows end-to-end with no human touch.
